## Our Advantages

### 1. True Data Sovereignty
Self-hosted default with local LLM (Ollama) means **no data ever leaves the customer's
environment**. This is a critical differentiator for:
- Companies handling sensitive pre-market device data
- Government contractors with security requirements
- Companies in heavily regulated jurisdictions

### 2. All-Device Coverage + AI/ML Specialization
MaudeSignal supports all device types with a general taxonomy AND has a specialized
AI/ML failure taxonomy — no competitor does both well.

### 3. Combined PMS + Technical Writing
Most tools separate PMS analysis from document generation. MaudeSignal does both —
from signal to PSUR draft — in one workflow.

### 4. Transparent, Auditable AI
Open-source Skills architecture with citation verification means every AI output is
auditable. Regulators and auditors can inspect exactly what the tool did and why.
No competitor offers this level of transparency.

### 5. Price Leadership
30–50% cheaper than the nearest comparable competitor, with a free Community tier
for startups and academic researchers.

### 6. Validation Package Included
Full IQ/OQ/PQ templates included — competitors charge extra or don't offer them.

## Target Wedge (Initial Market)

**Best early customers**: Small-to-mid MedTech companies (10–200 employees) that:
- Are currently using spreadsheets or basic tools
- Cannot afford Greenlight Guru / MasterControl
- Have AI/ML or SaMD devices requiring specialized surveillance
- Have security concerns about cloud data storage
- Need a Validation Package quickly for an FDA audit

**Approach**: Free/discounted pilots → case studies → paid expansion.
