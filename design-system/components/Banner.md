# Banner

A page-level notice: a tinted strip with a coloured icon and `ink` text.

**Provide:** one sentence and a leading icon.

- `info` (`accent-soft`), `warn` (`warning-soft`), `err` (`critical-soft`), `ok` (`success-soft`); the icon takes the status colour, the sentence stays `ink`.
- `radius-xs`, no side stripe.
