# Button

Paper-sharp rectangular actions: an ink `primary`, an outlined `secondary`, and two variants for the ink hero tile.

**Provide:** a verb-first label in sentence case; optionally a trailing 18px icon.

- One `ms-btn--primary` per region: `inverse` fill, `on-inverse` text, `radius-xs`.
- `ms-btn--secondary` is a 1px `ink` outline on transparent.
- On the hero tile use `ms-btn--on-inverse` (paper fill) and `ms-btn--ghost-inverse` (paper outline).
- 42px tall (`ms-btn--sm` 32px), `label` type. Focus shows the 2px `focus-ring`.
