# SignalList

The other signals in today's digest, numbered like a newspaper's further stories.

**Provide:** per row the running number (02, 03…), severity word, a title naming the failure, a meta line (product code · failure mode · confidence), and verification.

- Number in `index` serif `ink-3`; title in `title` serif; meta `body-sm`. Rows divided by `rule`; the whole row is the link and its title turns `accent` on hover.
