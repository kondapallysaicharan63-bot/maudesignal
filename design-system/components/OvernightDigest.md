# OvernightDigest (weekly digest layout sample)

Figures on this page are illustrative layout values, not data; the app shows real ones.

The overview page: Bar and dateline, then a 12-column bento grid.

**Provide:** the tiles in this order: HeroSignal (7×3), DeadlineRing (5×2), AISummary (5×1), four StatTiles (3×2 each), SeverityMix (6×2), SignalList (6×2).

- Grid rows 116px, gaps `space-4`, page gutter `space-10`, max width 1220px. Plain `paper` behind everything.
- Below 960px the grid collapses to 6 columns (hero and lists full width); below 640px to one column.
